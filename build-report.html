What Was Built

Two independent optimization tracks that can improve research agent instructions through automated experimentation. Each track edits one agent instruction file, runs a benchmark against cached ESP32-S3 documentation, scores the output with a deterministic Python scorer, and keeps or discards the change.

Track 1 (Haiku) optimizes a fast extraction agent. One Haiku agent processes 4 ESP32-S3 docs per experiment. Target: 30-40 experiments per hour.

Track 2 (Sonnet) optimizes a combined extraction+synthesis agent. One Sonnet agent processes 5 sources (including a community thread with real user reports). Target: 12-15 experiments per hour.
